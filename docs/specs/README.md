# Specifications

The active documents are `bias_dac_specification_summary_v0_2026-10-04.docx` and its detailed Markdown companion, revision 2.

From Week 7, use their working targets to guide device sizing, architecture decisions and simulations unless the user or mentor gives different instructions. Start from the 3-bit TG CDAC baseline; complete the ideal reset replacement and quantify errors before assessing 8-bit scaling. Do not automatically switch architectures or treat provisional numbers as mentor approval.

Every design change should identify the specification it addresses and retain its conditions, target, result and regression status. The actual load/interface, final bit count, total error allocation and validated cryogenic model remain decisions to close.
